# Crear Imagen Open Graph (og-image.png)

## Especificaciones Técnicas

- **Tamaño**: 1200 x 630 píxeles
- **Formato**: PNG o JPG
- **Tamaño máximo**: 8 MB (recomendado < 1 MB)
- **Ubicación**: `/public/og-image.png`

## Contenido Sugerido

La imagen debe incluir:

1. **Logo de Finantel** (grande y centrado)
2. **Texto principal**: "Finantel"
3. **Subtítulo**: "Gestión Financiera Personal Inteligente"
4. **Elementos visuales**:
   - Iconos de dinero/gráficos
   - Colores de la marca (#1C8FA0 - Turquesa)
   - Fondo atractivo y profesional

## Herramientas para Crear la Imagen

### Opción 1: Canva (Recomendado)
1. Ve a https://www.canva.com
2. Busca "Open Graph Image" o crea diseño personalizado de 1200x630
3. Usa la plantilla "Social Media" → "Facebook Post"
4. Diseña con los colores y logo de Finantel
5. Descarga como PNG

### Opción 2: Figma
1. Crea un frame de 1200x630
2. Diseña la imagen con el logo y texto
3. Exporta como PNG

### Opción 3: Generadores Online
- https://www.opengraph.xyz/
- https://metatags.io/
- https://ogimage.gallery/

## Colores Recomendados

- **Primario**: #1C8FA0 (Turquesa Finantel)
- **Fondo**: Degradado de #1C8FA0 a #167a8a
- **Texto**: #FFFFFF (Blanco)
- **Acento**: #E47B45 (Naranja)

## Pasos Después de Crear la Imagen

1. Guarda la imagen como `og-image.png`
2. Colócala en la carpeta `/public/`
3. Verifica que el archivo exista en: `/public/og-image.png`
4. Prueba el preview con:
   - Facebook Debugger: https://developers.facebook.com/tools/debug/
   - Twitter Card Validator: https://cards-dev.twitter.com/validator
   - LinkedIn Post Inspector: https://www.linkedin.com/post-inspector/

## Logo Temporal

Si necesitas un logo temporal, también debes crear:
- `finantel-logo.png` (512x512 px) - Para favicon y app icon

## Notas Importantes

- La imagen se mostrará cuando compartas links de Finantel en:
  - Facebook
  - Twitter/X
  - LinkedIn
  - WhatsApp
  - Telegram
  - Slack
  - Discord

- Una buena imagen OG puede aumentar el CTR en redes sociales hasta un 40%
