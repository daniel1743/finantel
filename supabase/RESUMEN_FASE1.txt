═══════════════════════════════════════════════════════════════════
  🐛 TROUBLESHOOTING COMÚN
═══════════════════════════════════════════════════════════════════

❌ "policy already exists"
  → Ejecuta DROP POLICY IF EXISTS manualmente

❌ "relation does not exist"
  → Ejecuta primero 000_migracion_completa_unificada.sql

❌ "function does not exist"
  → Ejecuta 004_mejoras_criticas.sql

❌ Las alertas automáticas no se generan
  → Verifica triggers: SELECT * FROM pg_trigger;
  → Asegúrate de tener datos que cumplan condiciones

❌ RLS bloquea mis queries
  → Verifica autenticación: SELECT auth.uid();
  → Revisa políticas: SELECT * FROM pg_policies;
